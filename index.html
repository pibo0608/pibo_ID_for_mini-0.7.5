MiNi 物品数据接口

本站为纯静态页面，所有数据来自 data/ 目录下的 JSON 文件。无需后端，开箱即用。

静态 JSON 本地加载 无跨域
GET 物品列表

获取指定版本的全部物品数据，包含 ID、名称、描述等信息。

/data/items.json?v=075
请求参数
v 可选 版本号，默认 075，仅用于缓存刷新
响应示例 200 OK 
[
  { "ID": 0, "Name": "空气", "Desc": "" },
  { "ID": 1, "Name": "土地", "Desc": "" },
  { "ID": 2, "Name": "草地", "Desc": "" },
  { "ID": 200, "Name": "果木", "Desc": "果木" },
  { "ID": 201, "Name": "落叶松木", "Desc": "落叶松木" }
]
GET 合成配方

获取指定版本的全部合成配方数据，前端根据物品名/ID 进行匹配查询。

/data/crafting.json?v=075
请求参数
v 可选 版本号，默认 075，仅用于缓存刷新
响应示例 200 OK 
[
  {
    "ID": 1,
    "ResultID": 206,
    "ResultName": "果木板",
    "ResultCount": 4,
    "GridX": 2,
    "GridY": 2,
    "Materials": [
      { "MaterialID": 200, "MaterialCount": 1 }
    ]
  },
  {
    "ID": 2,
    "ResultID": 207,
    "ResultName": "落叶松木板",
    "ResultCount": 4,
    "GridX": 2,
    "GridY": 2,
    "Materials": [
      { "MaterialID": 201, "MaterialCount": 1 }
    ]
  }
]
💡 前端通过 findRecipeByResultName() 或 findRecipeByResultId() 在 JSON 中查找匹配配方。
GET 主题定制

通过 URL 参数自定义页面配色与圆角，适合嵌入 iframe 或定制化展示。

/?color={hex}&radius={0-25}
请求参数
color 可选 十六进制颜色，# 需编码为 %23
radius 可选 卡片圆角，0–25 整数，默认 6
示例组合 
# 粉色主题 + 12px 圆角
/?color=%23ec4899&radius=12

# 仅修改配色
/?color=%233b82f6

# 仅修改圆角
/?radius=0
⚠️ URL 中 # 必须编码为 %23。支持 3/4/6/8 位 hex。
📦 数据格式规范

如果你要自己维护或扩展数据，请遵循以下格式。

items.json 字段
ID 必填 物品数字 ID，整数
Name 必填 物品中文名称
Desc 可选 物品描述/备注
crafting.json 字段
ID 必填 配方唯一编号
ResultID 必填 产出物品 ID
ResultName 必填 产出物品名称
ResultCount 必填 产出数量
GridX / GridY 必填 合成网格尺寸
Materials 必填 材料数组，每项含 MaterialID 和 MaterialCount
🚀 快速开始
JavaScript
cURL
// 加载物品数据
const items = await fetch('/data/items.json?v=075').then(r => r.json());
console.log(items); // [{ID:0, Name:"空气"}, ...]

// 前端搜索示例
function searchItems(query) {
  return items.filter(item => item.Name.includes(query));
}
console.log(searchItems('木')); // [{ID:200, Name:"果木"}, ...]

// 加载合成配方
const recipes = await fetch('/data/crafting.json?v=075').then(r => r.json());
console.log(recipes); // [{ResultID:206, ResultName:"果木板", Materials:[...]}]
# 获取物品数据
curl /data/items.json?v=075

# 获取合成配方
curl /data/crafting.json?v=075

# 主题定制访问
curl "/?color=%233b82f6&radius=12"
